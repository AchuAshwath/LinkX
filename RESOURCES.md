# LangChain & LangGraph Resources

## Knowledge

- [LangGraph Official Documentation — Conceptual Guides](https://langchain-ai.github.io/langgraph/concepts/high_level/)
  Foundational guide explaining State, Nodes, Edges, Graphs, and Multi-Agent patterns. Use for understanding graph compilation and execution semantics.
- [LangChain Core Docs — Chat Models & Tools](https://python.langchain.com/docs/concepts/chat_models/)
  Guide to `ChatOpenAI`, structured outputs (`with_structured_output`), and `@tool` decorators. Use for designing modular tool interfaces.
- [LangGraph How-To: Dynamic & Conditional Routing](https://langchain-ai.github.io/langgraph/how-tos/branching/)
  Practical guide on conditional edges (`add_conditional_edges`) for branching on failure, diagnosis, and retry. Use for self-healing loops.

## Wisdom (Communities)

- [LangChain GitHub Discussions & Issues](https://github.com/langchain-ai/langgraph/discussions)
  High-signal discussions on production agent design patterns, state management, and debugging.
